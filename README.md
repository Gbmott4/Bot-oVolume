# Botão de Volume

App Android que coloca um botão flutuante na tela para controlar o volume (feito para quem está com o botão físico quebrado).

## O que ele faz
- **Toque no botão:** abre os controles **−** e **+** e o painel de volume do sistema
- **Toque duplo:** liga/desliga o modo silencioso (pode desativar)
- **Arrastar:** muda o botão de lugar (ou fixe para não sair do lugar)
- **Configurações:** tamanho, cor, opacidade, toque duplo e fixar

Funciona no Android 8.0 ou mais novo.

## Como gerar o APK no GitHub
1. Crie um repositório novo no GitHub (pode ser privado).
2. Envie todos os arquivos desta pasta, **incluindo a pasta `.github`**.
3. O GitHub compila sozinho (aba **Actions**, leva uns 3–5 minutos).
4. Quando terminar, vá na aba **Releases** e baixe o `BotaoVolume.apk` direto no celular.

Toda vez que um arquivo for alterado, sai uma versão nova em Releases.

## Primeira vez no celular
1. Abra o `BotaoVolume.apk` e permita "instalar apps desconhecidos" quando o Android pedir.
2. Abra o app e toque em **Permitir aparecer sobre outros apps**.
3. (Opcional) Toque em **Permitir controlar o modo silencioso**, para o toque duplo deixar o celular em silêncio de verdade (sem isso ele usa o modo vibrar).
4. Toque em **Ligar botão**.

Dica: em alguns celulares (Xiaomi, Samsung, Motorola) vale tirar o app da economia de bateria, para o Android não fechar o botão sozinho.
